# 🌧️ 강수량 감소가 물 보유량에 미치는 영향 분석 (모로코 사례)

## 📌 프로젝트 개요

이 프로젝트는 **"강수량이 감소하면 물 보유량(수자원)도 감소하는가?"**라는 질문에서 출발했습니다.
강수량이 뚜렷하게 감소하는 국가인 **모로코(Morocco)**를 사례로, 강수량과 물 보유량의 관계를 데이터로 분석했습니다.

## ❓ 탐구 질문

> 강수량이 낮아지면 물 보유량(1인당 재생가능 담수 자원)도 낮아질까?

## 🔍 분석 대상

- **분석 국가**: 모로코(Morocco) 🇲🇦
- **분석 기간**: 1940년 ~ 2025년

## 📊 사용한 데이터

| 데이터 | 내용 | 출처 |
|--------|------|------|
| 연간 강수량 | 모로코 연평균 강수량 (mm) | Our World in Data |
| 1인당 재생가능 담수 자원 | 1인당 물 보유량 (㎥) | Our World in Data / FAO |

## 🛠️ 사용 기술

- **언어**: Python
- **라이브러리**: 
  - `pandas` - 데이터 처리
  - `numpy` - 추세선 계산
  - `plotly` - 인터랙티브 그래프
  - `streamlit` - 웹 대시보드
- **배포**: Streamlit Cloud

## 📈 분석 방법

1. 모로코의 연간 강수량 데이터를 선그래프로 시각화
2. `numpy.polyfit`으로 **추세선(1차 직선)**을 계산하여 강수량 증감 확인
3. 1인당 담수 자원 데이터를 함께 표시(이중 Y축)하여 두 값의 관계 비교

## 🔑 주요 발견

### 1. 모로코의 강수량은 감소하고 있다 📉
- 앞 절반(1940~1982) 평균: 약 314 mm
- 뒤 절반(1983~2025) 평균: 약 279 mm
- **약 11% 감소** (추세선 기울기: 음수)

### 2. 하지만 강수량과 물 보유량이 항상 같이 움직이진 않았다
- 강수량이 낮은 해라고 해서 물 보유량(1인당 담수 자원)이 반드시 낮지는 않았음
- 두 데이터가 **일치하지 않는 구간**이 존재함

## 💡 결론

> **강수량이 낮다고 해서 물 보유량이 반드시 낮은 것은 아니다.**

처음에는 "강수량이 줄면 물 보유량도 줄 것"이라고 예상했지만, 데이터 분석 결과는 달랐습니다.
그 이유로는 다음과 같은 점들을 생각해볼 수 있습니다:

- **물 보유량은 강수량만으로 결정되지 않는다**
  - 지하수, 강물, 빙하 등 다양한 수원(water source)의 영향을 받음
- **"1인당" 수치의 특성**
  - 1인당 담수 자원은 **인구 변화**의 영향도 크게 받음
  - 비가 비슷하게 와도 인구가 늘면 1인당 물은 줄어들 수 있음
- **물 저장 및 관리 시스템**
  - 댐, 저수지 등으로 물을 저장하면 강수량이 적어도 물을 확보할 수 있음
